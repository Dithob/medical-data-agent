持久化结构（对齐真实项目）

{ cards: [ {
  id, title, sql, dbConfigId,
  displayMode: table|chart|number,
  chartConfig: { chartType, xAxisField, yAxisFields },
  x, y, w, h
} ] }
保存失败降级 localStorage（key: dashboard-config-{id}）， 加载时接口失败也从本地恢复。

工程要点

  • 12 列栅格，卡片最小 1×1，拖拽只走头部手柄（避免与内部按钮冲突）
  • 布局变化写回 cards，用 x/y/w/h 描述位置与大小
  • 缩放后触发 ECharts resize()，配合 ResizeObserver
  • 每张卡片独立 loading / error，刷新用 Promise.allSettled 隔离失败
  • 组件销毁时 dispose 图表实例，避免内存泄漏
