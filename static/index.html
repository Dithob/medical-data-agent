问数流程

问题 → 指标 / 时间 / 维度 / 筛选条件
  → 不支持或歧义：明确提示
  → 参数化 SQL → 只读、限时执行
  → 白名单字段纠错（最多一次）
  → 结果 + 数据范围 + 截断提示
  → 图表 / 当前结果 Excel 导出

元数据召回在 trace 中展示；离线 SQL 生成使用固定 schema 与业务规则。

知识库流程

UTF-8 文档 → 稳定文档 ID / 不可变版本
  → 条款切分 → 最多 128 字符索引片段
  → 字符特征与词面匹配 → 阈值 / TopK
  → 抽取相关完整条款 → 引用对应文档版本

没有模型重排。上传更新后，旧回答仍可预览旧文档版本。

与原项目的区别

环节原项目资料描述本演示
编排与模型Dify / LangChain / Qwen3-32BPython 规则与原文抽取，未调用 LLM
检索与存储BGE-M3 / Milvus / MySQL词面特征 / 内存索引 / SQLite
前端Vue2 / Element UI / vue-grid-layout原生页面与栅格拖拽
文档PDF 解析和预览UTF-8 TXT / Markdown 版本预览
评测规模与效果原项目档案中的规模及效果口径独立本地回归，不能继承原项目成绩

示例业务数据与文档不来自真实企业。本 demo 不提供跨问题语义记忆、同比/环比或预测；库存默认最新可用快照。原项目重排是否落地仍以档案的条件说明为准。
